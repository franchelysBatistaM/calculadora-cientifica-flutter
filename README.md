# Scientific Calculator with Flutter

I developed this scientific calculator using Flutter and Dart as part of my programming practice.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Scientific functions: sine, cosine, tangent, square root, and logarithms.
- Exponentiation, percentages, and mathematical constants.
- Real time result previews.
- Error handling for invalid operations.

## Technologies

- Flutter
- Dart
